# Что сделать на сервере (для сокомандника)

Это короткая инструкция на русском: как обновить сервер до последней версии и собрать
20–30 пользователей для зачёта. Подробная техническая документация — в
[`README.md`](README.md), статус задач — в [`PROGRESS.md`](PROGRESS.md).

## Что нового в `main`

- **Вход и роли.** Без входа сайт не открывается. Рекрутер видит только свои сессии,
  администратор — все сессии и управляет пользователями.
- **Регистрация.** Администратор на странице «Пользователи» включает самостоятельную
  регистрацию (с кодом приглашения или без). При регистрации нужны логин, почта и пароль.
- **Лимит резюме:** 30 резюме в сутки на рекрутера (меняется там же, 0 — без лимита).
  Защищает баланс DeepSeek.
- **Статистика** (`/admin/stats`): сколько людей зарегистрировалось, входило, работало;
  график по дням и **Excel-отчёт** — это доказательство использования для преподавателя.
- **Журнал действий:** кто входил, открывал, выгружал, удалял.
- Экспорт в Excel и PDF, честная очередь между сессиями с оценкой оставшегося времени,
  автоудаление сессий старше 90 дней, бэкапы базы, проверенный Docker-образ.
- У каждого нового пользователя сразу есть сессия-пример с вакансией «Python-разработчик
  (Middle/Senior)» — можно сразу загружать резюме. Любую вакансию можно удалить.
- **Статусы кандидатов (SIS 10-11):** в рейтинге у каждого кандидата есть статус
  (Новый → Шорт-лист → Интервью → Оффер / Отказ) и заметка, фильтр по статусу и поиск
  по имени. Статус и заметка попадают в Excel, CSV и PDF.
- **Исправлено:** за туннелем все посетители были с одного IP (127.0.0.1), из-за этого
  после 5 регистраций за час регистрация закрывалась для всех. Теперь берётся настоящий IP
  из заголовка Cloudflare. Одну почту нельзя использовать для двух аккаунтов.
- **По отзывам пользователей:** число «Подходят» в рейтинге кликабельно и показывает
  только подходящих кандидатов; сайт нормально выглядит на телефоне; балл теперь цветной
  (зелёный / оранжевый / красный), а полоска видна.
- Тестов 361, все проходят. Реальный API в тестах не вызывается.

## 1. Обновить код

В папке проекта на сервере:

```bash
git pull
pip install -r requirements.txt        # появились argon2-cffi, openpyxl, fpdf2
```

(На Windows: `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.)

## 2. Проверить `.env`

Новых обязательных настроек нет. Ключ DeepSeek остаётся как был. Необязательные:

```
# сколько дней хранить сессии (0 — хранить всегда)
RETENTION_DAYS=90
```

Регистрацию и лимит резюме удобнее настраивать в самом приложении (шаг 5), а не в `.env`.

## 3. Создать администратора (один раз)

База на сервере своя, поэтому администратора нужно создать там:

```bash
flask --app app create-admin
```

Спросит логин и два раза пароль (минимум 10 символов; при вводе символы не видны — так
и должно быть).

## 4. Перезапустить приложение

Остановить старый процесс и запустить заново — так же, как вы запускали раньше
(`flask --app app run`, `waitress-serve ...` или Docker). При старте база обновится сама,
старые данные сохранятся.

- **Docker:** `docker build -t enbek-screen .`, затем остановить старый контейнер и
  запустить новый с тем же томом (`-v enbek-data:/app/instance`). Администратора
  создать так: `docker exec -it <контейнер> flask --app app create-admin`.

Проверка: `http://<адрес-сервера>/healthz` отвечает `{"status": "ok"}`, а главная страница
перекидывает на «Вход».

## 5. Открыть регистрацию

1. Войти под администратором → **Пользователи** → блок **«Регистрация»** справа.
2. Поставить галочку **«Разрешить самостоятельную регистрацию»**.
3. **«Требовать код приглашения»**: с галочкой люди вводят код, который вы им дадите;
   без неё хватает логина, почты и пароля. Сам код вписывается в поле
   **«Код приглашения»** ниже (см. «Про код приглашения»).
4. **Лимит резюме в сутки:** оставить 30 или поменять.
5. Нажать «Сохранить» — работает сразу, без перезапуска.

### Про код приглашения

- **Зачем:** без кода зарегистрироваться может любой, у кого есть ссылка, и тратить ваш
  баланс DeepSeek. С кодом — только те, кому вы его дали.
- **Какой:** любое слово или набор символов, например `ITPM2026`. Регистр важен:
  `itpm2026` и `ITPM2026` — разные коды. Код не хранится в репозитории, его знаете только вы.
- **Где задать:** «Пользователи» → «Регистрация» → поле «Код приглашения» → «Сохранить».
  Если стоит галочка «Требовать код», поле нельзя оставить пустым.
- **Как поменять:** вписать новый код и сохранить. Старый перестаёт работать сразу,
  уже созданные аккаунты остаются.
- **Как отключить:** снять галочку «Требовать код приглашения» — регистрация будет по
  логину, почте и паролю.
- **Защита от подбора:** после 5 неверных кодов с одного IP вход и регистрация с этого IP
  блокируются на 15 минут.
- **Через `.env` (необязательно):** строка `INVITE_CODE=ITPM2026` в `.env` сразу открывает
  регистрацию с этим кодом, пока администратор ни разу не сохранил блок «Регистрация».
  После сохранения действуют настройки из админки, а `.env` больше не важен.

## 6. Собрать пользователей

- Разослать одногруппникам **ссылку на сайт** и, если включён, **код приглашения**
  (лучше в личные сообщения или в закрытый чат группы, не публиковать открыто).
- Попросить каждого: зарегистрироваться → «Новый скрининг» → вставить текст вакансии
  (например, из `samples/vacancy_python_ru.txt`) → загрузить 2–3 резюме из
  `samples/resumes/` → открыть рейтинг → скачать Excel или PDF.
  Так в статистике будет видно не только регистрацию, но и реальную работу.
- Цель для зачёта: **20–30 человек**, которые вошли и создали хотя бы одну сессию
  (в статистике это «Активные»).

## 7. Показать преподавателю

- **Статистика** (`/admin/stats`): цифры, график по дням, таблица по каждому пользователю.
- Кнопка **«Скачать отчёт Excel»**: листы «Сводка», «По дням», «Пользователи» (с почтой)
  и «Журнал» — полный список действий со временем.
- Дополнительно: расход в личном кабинете DeepSeek.

## 8. Бэкап базы

```bash
python scripts/backup_db.py
```

Копия появится в `instance/backups/` (хранятся последние 14). Перед показом
преподавателю — обязательно сделать бэкап. Как запускать ежедневно — в README, раздел
«Data retention and backups».

## Правила

- **Не коммитить `.env`** и ключи — файл уже в `.gitignore`.
- Один процесс приложения на одну базу (не запускать две копии на одном `instance/app.db`).
- Перед пушем прогнать тесты: `pytest -q` (должно быть `361 passed`).

## Если что-то не так

- **«Нужно войти» / не пускает** — создайте администратора (шаг 3).
- **Нет ссылки «Зарегистрируйтесь»** — регистрация выключена (шаг 5).
- **«Неверный код приглашения»** — сверьте код с полем в «Регистрация»: важен регистр
  (большие и маленькие буквы).
- **Резюме падают с «баланс исчерпан»** — пополнить DeepSeek и нажать «Повторить неудачные» в сессии.
- **Рекрутер не может загрузить резюме** — исчерпан суточный лимит; поднимите его в
  «Регистрация» или подождите сутки.
